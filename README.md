Tower Turn

A simple Browser game made by me for stacking blocks and it is totally cool ahahaha

Features

* Drop blocks on top of each other and slice off and get perfect matches
* also it automatically moves the camera up whenever the tower gets tall, high , normal
* the block dropping is very fast .... just in one click
* special cool flat 3d designs
* Turn button and Unlockable perks
* Simple and clean

How To Use

* Wait for the block to slide over the tower
* Click anywhere to drop it
* and lets goooo


Tech Stack

* HTML
* CSS
* JavaScript
